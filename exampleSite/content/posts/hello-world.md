折腾了一圈现成的 Hugo 主题之后，还是决定自己写一套。这篇记录一下过程和思路。

## 为什么自己做主题

现成主题有两个问题：

- **审美不合**：翻遍主题库也找不到完全合心意的那一套；
- **改起来更绕**：为了改一个细节，得先读懂别人几百行的模板结构，再想办法覆盖。

而 Hugo 主题的本质其实很简单——**HTML 模板 + CSS**，没有框架、没有构建工具链。最小可用的主题只要三个文件。

## 设计语言

整体参考了像素复古（pixel / 8-bit）风格：

- 配色取自经典的 **Sweetie 16** 像素画调色板
- 零圆角、2px 实线边框、**实心错位硬阴影**
- 标题使用 **缝合像素字体**，正文保持无衬线，兼顾可读性

## 工程结构

主题被拆成了清晰的分层，方便后续迭代：

```
themes/pixel-blog-hugo/
├── assets/
│   ├── css/        # tokens / base / layout / components / markdown / home
│   ├── js/         # 明暗切换、移动菜单、回到顶部
│   └── images/     # 像素 logo
├── i18n/           # 中英文案
├── layouts/        # 模板与 partials
└── theme.toml
```

样式通过 **Hugo Pipes** 拼接、压缩、加指纹；主题细节用 CSS 自定义属性承载，明暗两套只需切换根节点 class。

首页的个人信息文案（`params.hero`）、顶部栏名称与 logo（`params.identity`）、个人作品（`params.works`）都集中在 `hugo.toml` 里，改内容不用动模板。

> 目标是：**改一个色值，全站生效。**
